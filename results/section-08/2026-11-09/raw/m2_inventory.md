## Changes, and the M1 case that shows each

| ID | Change | M1 |
|---|---|---|
| `autoclass` | autoclass(...) becomes ObjCClass(...) | `strings` |
| `load_framework` | load_framework(...) becomes load_library(...) | `delegate` |
| `utf8string` | .UTF8String() becomes str(...); in Rubicon UTF8String is a property giving bytes | `strings` |
| `bytes_check` | a bytes check after UTF8String() is no longer needed with str(...) | `strings` |
| `count` | .count() on an NSArray becomes len(...) | `property_call` |
| `objc_str` | objc_str(x) becomes x | `defaults` |
| `objc_arr` | objc_arr(...) becomes a list | `collections` |
| `init_utf8` | initWithUTF8String_(s) takes bytes, or pass the str directly | `strings` |
| `protocol` | a @protocol(...) method moves to an NSObject subclass with @objc_method | `delegate` |
| `delegate_self` | a Python object set as delegate becomes an instance of that subclass, kept alive by Python | `delegate` |
| `bool_return` | return ObjcBOOL(...) becomes a -> bool annotation | `Section 3 F3.7` |
| `error_alloc` | an NSError object passed for an NSError ** argument becomes byref(objc_id()) | `nserror_out` |
| `completion_nil` | None for a completion block still works; a Python function can now be passed | `block` |
| `property_or_method` | a try/except or callable() check for property versus method can go | `search_path` |
| `nsarray_index` | objectAtIndex_(i) loops can become indexing or iteration | `languages` |
| `property_parens` | a zero-argument call of a name Rubicon reads as a property loses its `()` | `zero_arg`, `zero_arg_ios` |
| `property_both` | a zero-argument call of a name that's a property in pyobjus too, so its `()` would raise in either library | `zero_arg`, `zero_arg_ios` |

## Read by hand

- `plyer/platforms/ios/accelerometer.py`, `plyer/platforms/ios/barometer.py`, `plyer/platforms/ios/compass.py`, `plyer/platforms/ios/gravity.py`, `plyer/platforms/ios/gyroscope.py`, `plyer/platforms/ios/spatialorientation.py`: Poll kivy-ios's template `bridge` class, which runs CoreMotion's block-based updates in Objective-C. Rubicon calls the `bridge` unchanged (M1 `app_class`), or can pass Python functions to CoreMotion directly, as Section 4 E3 does for the barometer. Its `ac_x` and similar values are properties in `bridge.h`.
- `plyer/platforms/ios/filechooser.py`: Calls kivy-ios's `NativeImagePicker` for `UIImagePNGRepresentation`, a C function. Rubicon calls the class unchanged, or the function through `ctypes` (Section 3 F1.5). Plyer 2.1.0's `open_file()` raised `TypeError` on the iPhone, with pyobjus 1.2.4 and `master`, at `keyWindow.rootViewController()` (line 59): `rootViewController` is a property in both libraries, so the `()` raises in either, and the picker never opens (window test). Read without `()`, the picker opened in both libraries, with a Rubicon delegate in Rubicon. `load_framework` takes Photos' folder path, which Rubicon's `load_library` rejects with `ValueError`; `load_library("Photos")` works.
- `plyer/platforms/ios/voip.py`, `plyer/platforms/ios/frameworks/utils.py`: Loads Plyer's bundled `Voip.framework` by its folder path. Rubicon's `load_library` rejects a framework folder path with `ValueError`, and loads the binary inside it, as the window test found for Photos; the bundled `Voip.framework` itself isn't tested. `self.error`, an `NSError` object, is passed to `setCategory_mode_options_error_` and `setActive_error_`, the form that crashed pyobjus when an error was written (M1 `nserror_out`).
- `plyer/platforms/macosx/audio.py`: Passes `NSError.alloc()` to `initWithURL_format_error_` and `initWithContentsOfURL_error_`, the form that crashed pyobjus when an error was written (M1 `nserror_out`).
- `plyer/platforms/ios/flash.py`: Writes `AVMediaTypeVideo` as `"vide"`. Rubicon can read the constant with `objc_const` (M1 `constant`).
- `plyer/platforms/ios/gps.py`, `plyer/platforms/macosx/gps.py`: Parses latitude, longitude and accuracy out of `location.description` instead of reading the `coordinate` struct. Reading that struct in Rubicon isn't tested here; M1 read `frame` and `bounds` structs in both.
- `plyer/platforms/ios/uniqueid.py`: Calls `identifierForVendor.UUIDString()`. M1 found `UUIDString` is a property in pyobjus 1.2.4, `master` and Rubicon, on an `NSUUID` from `NSUUID.UUID()` on the Mac and the iPhone, so the `()` would raise in either. `identifierForVendor` itself wasn't run.
- `kivy/core/audio_output/audio_avplayer.py`: The `Sound` subclass is its own delegate. M1's `delegate` case is this code: in Rubicon the delegate becomes an `NSObject` subclass that the `Sound` keeps a reference to.
- `kivy/core/clipboard/clipboard_nspaste.py`: Raises `SystemError` with a `pip install --user pyobjus` hint when the import fails, which names the library.
